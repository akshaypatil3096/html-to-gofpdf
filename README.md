# html-to-gofpdf

Field

Description

session_id

Unique identifier of the user session during which the transaction occurred. Common across all events within the same browser or mobile app session.

customer_id

Unique customer identifier associated with the transaction.

account_number

Account involved in the transaction, if applicable. Can be masked or unavailable (NA) for non-account-specific events.

device_id

Unique device identifier. For mobile apps, typically a device UUID/installation ID. For browsers, may be unavailable (NA).

device_os_platform

Operating system platform from which the request originated (e.g., Android, iOS, Windows, macOS, Linux).

device_os_version

Version of the operating system running on the client device.

device_name

Device model or hostname. For mobile: iPhone 15, Samsung S24, etc. For browsers: may be unavailable or generic.

ip_address

Client IP address from which the request originated.

location

Geographic location associated with the request, typically derived from IP geolocation or device location services.

proxy_ip_address

IP address observed after passing through proxy, load balancer, CDN, or network gateway.

browser_version

Browser name and version for web channels. For mobile apps, may contain embedded WebView version or NA.

user_agent

Complete User-Agent string received from the client, useful for device and client identification.

channel_platform

Business channel through which the transaction originated (e.g., Retail Banking, Mobile Banking, Internet Banking, Partner Portal).

channel_id

Unique code identifying the specific channel or application.

app_version

Version of the client application. For mobile apps, the app build/version. For browsers, can represent portal/frontend version.

environment

Deployment environment where the transaction was processed (DEV, SIT, UAT, STG, PROD).

language_id

User-selected or detected language used during the transaction.

app_id

Identifier of the application/service that generated the transaction event.

maker_id

User ID of the creator/initiator of a transaction in maker-checker workflows.

maker_timestamp

Timestamp when the maker created or submitted the transaction.

checker_id

User ID of the approver in maker-checker workflows.

checker_timestamp

Timestamp when the checker approved or rejected the transaction.

correlation_id

Unique identifier used to trace a request across multiple microservices and systems.

txn_id

Business transaction identifier used to uniquely identify the transaction or operation.

request

Serialized request payload received by the service. Sensitive fields should be masked before logging.

response

Serialized response payload returned by the service. Sensitive data should be masked.

status

Final processing status of the transaction (SUCCESS, FAILURE, PENDING, MFA_SUCCESS, etc.).

error_response_message

Detailed error message returned during transaction failure.

error_response_code

Standardized error code associated with the failure.

server_name

Hostname, pod name, or instance name that processed the transaction.

risk_engine_triggered

Indicates whether fraud/risk evaluation was triggered for this transaction.

mfa_applicable

Indicates whether Multi-Factor Authentication was applicable for the transaction.

transaction_logger_uuid

Unique identifier generated by the logging framework for the audit event.

start_timestamp

Timestamp when transaction processing started.

end_timestamp

Timestamp when transaction processing completed.

additional_info

Free-form metadata or supplementary information related to the transaction.

ui_error_message

User-facing error message displayed on the client application.

subscription_name

Pub/Sub subscription that consumed or processed the message. Useful for troubleshooting event flow.

attributes

Pub/Sub message attributes or additional metadata attached to the event.

publish_time

Timestamp when the message was published to the Pub/Sub topic.

message_id

Unique Pub/Sub message identifier assigned upon publication.

endpoint

API endpoint or resource path invoked by the client during the transaction.
